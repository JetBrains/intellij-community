Reports a non-null parameter that some call site passes the null literal to.

Example:

class Greeter {
  void greet(@NotNull String name) {
    System.out.println("Hello, " + name);
  }

  void run() {
    greet(null); // 'name' is reported
  }
}

Such a call breaks the not-null contract of the parameter. Either the argument must become non-null, or the parameter must accept null.

The Navigate to 'null' argument usages quick-fix shows every such call site.

The inspection must search the whole project for the call sites, so it works in the editor only. It reports nothing in batch mode. In batch mode, you still get the call-site reports from the Nullability and data flow problems inspection.
