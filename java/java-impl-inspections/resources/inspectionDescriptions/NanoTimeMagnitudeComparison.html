Reports comparisons of a System.nanoTime() value with another value using <, >, <= or >=.

Values returned by System.nanoTime() are meaningful only when one is subtracted from another. The absolute values can be negative and can overflow, so a direct magnitude comparison of two such values can give a wrong result once the difference between them crosses the overflow boundary. As the method documentation states, you should use t1 - t0 < 0, not t1 < t0.

Example:


  long deadline = System.nanoTime() + timeoutNanos;
  while (System.nanoTime() < deadline) { // warning: magnitude comparison
    // ...
  }

Rewrite the loop to compare the difference:


  long start = System.nanoTime();
  while (System.nanoTime() - start < timeoutNanos) {
    // ...
  }

The inspection reports only a direct System.nanoTime() call on one side of the comparison. The correct idiom, which subtracts first and compares the difference, is not reported.
