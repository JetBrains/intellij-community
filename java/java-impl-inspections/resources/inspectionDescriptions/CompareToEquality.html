Reports .compareTo() calls whose result is compared with 0 using == or != to check for equality. A direct equals() call expresses the intent more clearly.

Not all classes have a compareTo() implementation that is consistent with equals(). Currently, compareTo() calls on the following class types can be reported:

  • java.lang.String
  • java.lang.Enum, i.e. all enum classes
  • java.lang.Number subclasses, but not java.math.BigDecimal
  • java.lang.Character
  • java.lang.Boolean
  • Most classes from the java.time package e.g. java.time.LocalTime
The inspection does not report when the argument may be null, because compareTo(null) throws a NullPointerException while equals(null) returns false, so the replacement would change behavior.

The quick-fix is available even when nothing is reported, so it's always possible to convert compareTo() method call expressions to equals() calls.

Example:


  boolean isSame(String name) {
    return name.compareTo("value") == 0;
  }

After the quick-fix is applied:


  boolean isSame(String name) {
    return name.equals("value");
  }
