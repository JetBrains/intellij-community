Reports .compareTo() calls whose result is compared with 0 using == or != to check for equality. A direct equals() call expresses the intent more clearly. Not all classes have a compareTo() implementation that is consistent with equals(), so currently only calls on String, Enum and Number but not java.math.BigDecimal expressions are reported.

Example:


  boolean isSame(String name) {
    return name.compareTo("value") == 0;
  }

After the quick-fix is applied:


  boolean isSame(String name) {
    return name.equals("value");
  }

The inspection does not report when the argument may be null, because compareTo(null) throws a NullPointerException while equals(null) returns false, so the replacement would change behavior.
