# Decision records of the UI-lane controller

These records decide the UI-lane controller in `community/tools/vm`. They moved here from
`plugins/air/docs/decisions`.

A moved record keeps the number that it had in `plugins/air/docs/decisions`. Thus the sequence in this directory has
gaps. A new record takes the next number after the highest number in this directory.

Each moved record has a `topic:` frontmatter. The Air docs site used it. Here it has no function.

Some records decide both the Kotlin lane and the controller. These records stay in `plugins/air/docs/decisions`:
0061, 0064, 0104, 0112, 0113, 0137, 0155, 0159, 0164 and 0200. The records of BT also stay there: 0017, 0070 and 0107.
