  Default Shortcuts by Key Combination
Using shortcuts is a major key to gaining maximum efficiency and productivity working with IDEA. This topic lists keystroke combinations and their functions for the Default keymap (set in File | Settings: IDE: Keymap). Note that the key combinations documented in this topic may not perform the function described if you are using a different, customized keymap.

The key combinations in the topic are categorized as follows:
     Alt + Key:
       Alt + Alpha-numeric key

Alt + Key

Alt + Alpha-numeric Key:
Keystroke Function
Alt + O Export to Text File: Export a tool window's content to a text file
Alt + Q Context Info: Show the current method or class declaration when it is not visible
Alt + <number> Open tool window: Open a tool window with the corresponding number

Alt + Navigation keys:
Keystroke Function
Alt + Backspace Undo: Undo last operation. Alternative: Ctrl + Z
Alt + Delete Safe Delete: Delete a selected class/method/field checking its usages
Alt + Enter Show Intention Action: Display intention actions (if any) for a code where the caret is currently located.
Alt + Insert In navigation tool windows: New...: Create a new class, interface, file or directory

In the Editor: Generate: Generate constructor, getter or setter method, or EJB components
Alt + Down Go to Next Method: Navigate to the next method declaration in the active editor tab
Alt + Left Select Previous Tab: When several tabs are open in the editor or a view, opens the next tab to the left (or last tab if current one is the first)
Alt + Right Select Next Tab: When several tabs are open in the editor or a view, opens the next tab to the right (or first tab if current one is the last)
Alt + Up Go to Previous Method: Navigate to the previous method declaration in the active editor tab

Alt + Function (F) keys:
Keystroke Function
Alt + F1 Select in...: Select the current class or method in any view

In Project tool window: Change View: Choose Project, Sourcepath or Classpath tree in the Project View tool window

In Commander tool window: Change Left View: Change the left panel contents
Alt + F2 Change Right View: In Commander: Change the right panel contents
Alt + F3 Incremental Search: Call the Incremental Search popup
Alt + F6 Synchronize Views: In Commander tool window: Synchronize both panels
Alt + F7 Find Usages: Call the Find Usages dialog
Alt + F8 Evaluate Expression: Evaluate an arbitrary expression
Alt + F9 Run to Cursor: Run to the line where the caret is located

Alt + Navigation keys:
Keystroke Function
Alt+ Shift + Backspace Backspace: Redo last Undo operation. Alternative: Ctrl + Shift + Z

Ctrl + Key

Ctrl + Alpha-numeric keys:
Keystroke Function
Ctrl + A Select All: Select an entire text opened in the editor
Ctrl + B Go to Declaration: Navigate directly to an element's declaration from any usage
Ctrl + C Copy: Copy the selected text to the clipboard
Ctrl + D Duplicate Line or Block: Duplicates a selected block or a line at which the caret is currently located
Ctrl + E Recent Files: Show recently edited files list
Ctrl + F Find: Call the Find Text dialog.
Ctrl + G Go to Line: Navigate to any line in the current file by specifying the line number
Ctrl + H Type Hierarchy: Browse hierarchy for the selected class
Ctrl + I Implement methods: Override base interface/class methods in the current class
Ctrl + J Insert Live Template: Show a popup list of Live Templates starting with a specified prefix
Ctrl + M Scroll to Center: Scrolls a line with a caret to the screen center
Ctrl + N Go to Class: Navigate directly to any class in the project by specifying its name in a pop-up dialog
Ctrl + O Override Methods: Override base class methods in the current class
Ctrl + P Parameter Info: Show parameters of the method call at the caret
Ctrl + Q Quick Javadoc: Show a popup window with Javadoc for the symbol at the caret. Alternative: Alt + Button2 Click
Ctrl + R Replace: Call the Replace Text dialog
Ctrl + S Save All: Save all files and settings
Ctrl + U Go to Super Method: Navigate to a super method declaration of a method under the caret

In Commander tool window: swap panels
Ctrl + V Paste: Paste from clipboard. Alternative: Shift + Insert
Ctrl + W Select Word at Caret: Selects a word at which the caret is currently located. For Java files, successively selects expanding blocks of code. (Use repeatedly to accurately select expressions!)
Ctrl + X Cut: Cut to clipboard. Alternative: Shift + Delete
Ctrl + Y Delete Line at Caret: Deletes a word starting from the current caret location up to the word end
Ctrl + Z Undo: Undo last operation. Alternative: Alt + Backspace Redo: Ctrl + Shift + Z
Ctrl + <number> Go to bookmark: Navigate to a numbered bookmark with corresponding number

Ctrl + Navigation keys:
Keystroke Function
Ctrl + Backspace Delete to Word Start: Deletes a word starting from the current caret location up to the word start
Ctrl + Delete Delete to Word End: Deletes a word starting from the current caret location up to the word end
Ctrl + End Move to Text End: Moves the caret to a text end
Ctrl + Enter In Editor: Split Line: Intelligently split the current line into 2 lines, shifting quotes, etc. as necessary

In Tool Windows: Open an Editor tab for the selected item and give it focus
Ctrl + Home Move to Text Start: Moves the caret to a text start
Ctrl + Insert Copy: Copy a current line or a selected code block to clipboard. Alternative: Ctrl + C
Ctrl + Spacebar Basic Code Completion: Code completion for any class, method or variable
Ctrl + Page Down Go to Page Bottom: Moves the caret down to the page bottom
Ctrl + Page Up Go to Page Top: Moves the caret up to the page top
Ctrl + Down Scroll Down: Scroll the text one line down while moving the caret to the previous line. Alternative: Ctrl + Shift + Down
Ctrl + Left Move to Previous Word: Moves the caret to the previous word
Ctrl + Right Move to Next Word: Moves the caret to the next word
Ctrl + Up Scroll Up: Scroll the text one line up while moving the caret to the next line. Alternative: Ctrl + Shift + Up

Ctrl + Symbol keys:
Keystroke Function
Ctrl + [ Move to Code Block Start: Moves the caret to the current code block start highlighting the block limits
Ctrl + ] Move to Code Block End: Moves the caret to the current code block end highlighting the block limits
Ctrl + / Comment with Line Comment: Comment/uncomment current line or selected block with line comments. Alternative: Ctrl + Numpad/
Ctrl + = Expand All: Expand all folding blocks. Alternative: Ctrl + Numpad+
Ctrl + Minus Collapse All: Collapse all folding blocks. Alternative: Ctrl + Numpad-

Ctrl + Numpad keys:
Keystroke Function
Ctrl + Numpad/ Comment with Line Comment: Comment/uncomment current line or selected block with line comments. Alternative: Ctrl + /
Ctrl + Numpad+ Expand All: Expand all folding blocks. Alternative: Ctrl + =
Ctrl + Numpad- Collapse All: Collapse all folding blocks. Alternative: Ctrl + Minus

Ctrl + Function (F) keys:
Keystroke Function
Ctrl + F1 Error Description: Show an error or warning description at the caret
Ctrl + F3 Find Word at Caret: Search in the editor for the word where the caret is currently located
Ctrl + F6 Change Method Signature: Refactor a selected method signature and update all references
Ctrl + F7 Find Usages in File: Call the Find Usages dialog
Ctrl + F8 Toggle Breakpoint: Toggle breakpoint at a current line
Ctrl + F9 Build Project: Compile all modified and dependent files in a project
Ctrl + F12 File Structure Popup: Popup the current file structure for quick navigation

Keystroke Function

Ctrl + Shift + Insert Paste: Paste from recent clipboards. Alternative: Ctrl + Shift + V

Shift + Key

Shift + Navigation keys:
Keystroke Function
Shift + Backspace Backspace: Delete a character to the left of the caret. Alternative: Backspace
Shift + Delete Cut: Cut a current line or a selected code block to clipboard. Alternative: Ctrl + X
Shift + Down Down with Selection: Move the caret one line down selecting the text
Shift + End Move to Line End with Selection: Move the caret to a line end selecting the text
Shift + Enter Start New Line: Start a new line after the current one positioning the caret in accordance with the current indentation level (equal to sequential pressing End, Enter)
Shift + Escape Hide Active Window: Hide the currently active tool window
Shift + Home Move to Line Start with Selection: Move the caret to a line start selecting the text
Shift + Insert Paste: Paste from clipboard. Alternative: Ctrl + V
Shift + Left Left with Selection: Move the caret one character to the left selecting the text
Shift + Page Down Page Down with Selection: Move the caret one page down selecting the text
Shift + Page Up Page Up with Selection: Move the caret one page up selecting the text
Shift + Right Right with Selection: Move the caret one character to the right selecting the text
Shift + Tab Unindent Selection: Move a selected block to the previous indent level
Shift + Up Up with Selection: Move the caret one line up selecting the text

Shift + Function (F) keys:
Keystroke Function
Shift + F1 External Javadoc: Open browser with Javadoc for the selected item
Shift + F2 When editing: Go to Previous Highlighted Error: Navigate to the previous found error/warning

When debugging: Stop Program Terminate a debugging session
Shift + F3 Search for next/previous occurrence: Navigate to the next/previous occurrence of a selected word in the editor. Alternative: F3
Shift + F5 Clone: Create a selected class copy in the same package
Shift + F6 Rename: Rename a selected statement and correct all references. (Refactoring)
Shift + F7 Move to Previous Difference: Move to a previous difference in a view
Shift + F8 Step Out: Step to the first executed line after returning from a current method
Shift + F9 Debug: Debug a program
Shift + F10 Run: Run a program
Shift + F12 Restore Default layout: Restore a default IDEA layout (tool windows position state, tool window buttons location and order). The default layout can be set by selecting Store Current Layout as Default in the Window menu.

Navigation Keys

Keystroke Function
Delete 1. In the editor: delete selected symbol/block
2. In a usage view: exclude a selected item
3. In other views: remove selected item(s)
Down Move down: Move the caret one line down
End Move to Line End: Move the caret to a line end
Home Move to Line Start: Move the caret to a line start
Insert Toggle Insert/Override: Toggle insert/override modes
Left Move left: Move the caret one character to the left
Page Down Page down: Move the caret one page up
Page Up Page up: Move the caret one page up
Right Move right: Move the caret one character to the right
Tab 1. In the editor:
  • With any selection: indent selected line(s)
  • Without any selection: insert a tab symbol (or corresponding number of space characters)
2. In a lookup list:
  • No code after the caret in the editor: select an item (like Enter)
  • Some code after the caret in the editor: select an item and substitute the code after the caret with it
Up Move up: Move the caret one line up

Function (F) Keys

Keystroke Function
F1 Help: Invoke context-sensitive online Help
F2 Activate in-place editing: In a GUI Designer form, activate in-place editing of the name of a selected UI component.
F3 Search for next/previous occurrence: Navigate to the next/previous occurrence of a selected word in the editor. Alternative: Shift + F3
F4 Edit Source: Open an editor tab for the selected item and give it focus
F5 Copy: Create a copy of a selected class/file/directory in the same or a different package
F6 Move: Move a selected class/package/static member to another package/class and correct all references
F7 Step Into: Step to the next executed line (during debugging)
F8 Step Over: Step to the next line in the current file (during debugging)
F9 Resume Program: Resume program execution (during debugging)
F12 Jump to Last Window: Activate a last focused tool window
