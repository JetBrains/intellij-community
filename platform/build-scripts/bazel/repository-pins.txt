# Per-library repository pins for the JPS -> Bazel @lib generator (jpsModelToBazel).
#
# When resolving a NEW or version-bumped library jar, the generator otherwise probes every
# <remote-repository> in .idea/jarRepositories.xml in order (a HEAD per repo) until one returns 200.
# A pin here makes it query only the named repository instead. Already-resolved jars are cached in the
# committed lib/MODULE.bazel; Bazel build-time fetches are always hermetic.
#
# Format:  <maven group prefix OR group:artifact>   <repository id from .idea/jarRepositories.xml>
#  - a key without ':' matches that group and its subgroups; a key with ':' is an exact group:artifact
#  - the longest matching key wins; '#'/blank lines are ignored
#  - a pinned artifact absent from its repository is a hard error (surfaces a wrong pin)
#
# Generated (MRI-4573) from the current lib/MODULE.bazel + community/lib/MODULE.bazel by mapping each
# artifact's resolved URL back to its repository. Groups whose artifacts span multiple repositories are
# pinned per group:artifact. Regenerate/extend as dependencies change.
