# Eel Overview

Architecture and strategic goals. These documents are useful for every reader: API users, Eel and IJent developers, and AI agents.

- [Eel Architecture](architecture.md) explains the goal of Eel, the `EelDescriptor`, `EelMachine`, and `EelApi` model, and how Eel relates to IJent.
- [Two File System APIs](file-systems.md) explains `EelFileSystemApi` with `EelPath`, `java.nio.file` with `MultiRoutingFileSystem`, and why NIO is the primary API.
- [Eel API as Run Targets 2.0](EelApi_as_Run_Targets_2.0.md) explains why Eel replaced Run Targets, the IJent technology behind it, and the future directions.
