# Plugin Manager Specifications

Plugin manager behavior specifications start at the [specification index](../../../../../spec/plugin-manager/README.md).

Before you change a test, compare it with each specification `targets` field and `[@test]` link.

Read each matching specification. Keep its test links accurate when test ownership changes.

If a test exposes existing drift, report the requirement and evidence.
Continue when the change remains safe. Repair the drift in a separate commit.

A test without a matching target or link has no specification duty.
