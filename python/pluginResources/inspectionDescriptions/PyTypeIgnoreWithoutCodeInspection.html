Reports a # type: ignore comment that names no known inspection code.

Such a comment suppresses every inspection on its line. A comment in the leading comments of the file suppresses every inspection in the file. It can therefore hide a problem that appears there later.

A code of another type checker, such as mypy's attr-defined, names no inspection of this IDE. Such a comment gets the same report.

Name the inspection codes in brackets to suppress only the problems that you accept. For example, write # type: ignore[PyTypeChecker] or # type: ignore[pycharm:PyTypeChecker].
