Reports a PyCharm code in a # type: ignore or # pycharm: ignore comment that names no inspection.

A PyCharm code has the pycharm: namespace, as in # type: ignore[pycharm:unsupported-operatr], or it stands in a # pycharm: ignore comment. A code that names no inspection suppresses nothing.

A bare code in # type: ignore, such as mypy's attr-defined, is not reported, because other type checkers use their own codes there. A name that starts with Py and a capital letter is not reported either, because it can name an inspection of another edition or of a disabled plugin.

The quick fix removes the unknown code. The fix is not available when only codes of other type checkers stay, because such a comment suppresses every inspection on its line.
