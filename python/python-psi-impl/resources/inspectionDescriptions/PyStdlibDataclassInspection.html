Reports invalid definitions and usages of classes decorated with @dataclasses.dataclass from the standard dataclasses module.

Detected problems include mutable default values used without default_factory, InitVar fields declared without a __post_init__ method, a __post_init__ signature that doesn't match the declared init-only variables, and conflicting dataclass arguments or hand-written dunder methods.

Example:


import dataclasses


@dataclasses.dataclass
class FullName:
    first: str
    middle: str = ""
    last: str
