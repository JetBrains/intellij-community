Reports invalid definitions and usages of classes recognized through a @dataclass_transform()-decorated base class, metaclass, or decorator, as defined by PEP 681.

Detected problems include conflicting dataclass arguments or hand-written dunder methods, inconsistent frozen settings across a class hierarchy, and field(...) calls that specify both default and default_factory.

Example:


from typing import dataclass_transform


@dataclass_transform()
class ModelBase:
    ...


class User(ModelBase):
    name: str
