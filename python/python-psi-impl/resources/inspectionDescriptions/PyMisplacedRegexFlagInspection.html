Reports a flag of the re module, for example re.IGNORECASE, that is passed as an argument that takes another number: pos or endpos of a method of a compiled pattern, maxsplit of split(), or count of sub() and subn(). The function takes the flag as that number, so the flag has no effect.

Example:


import re

regex = re.compile(r'\wo\w')
match = regex.search('foo bar', re.I)
text = re.sub(r'o', '0', 'Foo', re.I)

As a fix, pass the flag to re.compile(), for example re.compile(r'\wo\w', re.I), or pass it to a function of the re module as the keyword argument flags.
