Reports a type parameter default (PEP 696) that can never be used because a parameter typed with that type variable has its own default value.

When such a parameter is omitted, its default value determines the type variable; when an argument is supplied, the argument determines it. Either way the declared type parameter default is never applied. 


def f[T = int](a: T = 0) -> T:  # 'int' is never used: f() yields Literal[0], f(x) yields the type of x
    return a
