Reports invalid definitions and usages of classes created with the attrs library (attr.s/attr.ib).

Detected problems include hand-written methods that conflict with ones attrs would generate (such as __init__, __repr__, or comparison methods), invalid @<attribute>.default or @<attribute>.validator decorated methods, conflicting default/factory arguments, and an incorrect __attrs_post_init__ signature.

Example:


import attr


@attr.s
class Point:
    x = attr.ib()
    y = attr.ib()
