# WebView plugins

The WebView plugins moved to the [intellij-webview](https://github.com/nerzhulart/intellij-webview) repository.

Use these replacements:

| Previous plugin ID | New plugin ID |
| --- | --- |
| `com.intellij.platform.ui.webview` | `io.github.nerzhulart.webview` |
| `com.intellij.platform.ui.webview.demo` | `io.github.nerzhulart.webview.demo` |
| `org.intellij.plugins.markdown.webview.preview` | `io.github.nerzhulart.markdown` |

The [WebView Runtime plugin](https://plugins.jetbrains.com/plugin/33513-webview-runtime-experimental-/versions?noRedirect=true) is available in JetBrains Marketplace.

The [Markdown Lens plugin](https://plugins.jetbrains.com/plugin/33921-markdown-lens/) will be available there soon.
