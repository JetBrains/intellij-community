Reports a MutableStateFlow that holds a mutable collection.

A state flow compares a new value with the current one by Any.equals. A mutating change of the collection keeps the same instance, so the state flow emits nothing. Every collector misses the change.

Use a read-only collection type instead. A read-only type turns each mutation into a compilation error. Assign a new collection to value to emit a change.

Example:


  val state = MutableStateFlow(mutableListOf<Int>())

  fun add() {
      state.value.add(1) // The state flow emits nothing.
  }

After the quick-fix is applied:


  val state = MutableStateFlow(listOf<Int>())

  fun add() {
      state.value.add(1) // Compilation error.
  }

The quick-fix changes the initial value only. Replace each mutation with an assignment: 


  fun add() {
      state.value = state.value + 1 // The state flow emits a new value.
  }
