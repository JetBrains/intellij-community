Reports usages of fastjson2 or fastjson2-kotlin in Kotlin code when kotlin-reflect is missing from the containing module's classpath.

According to the Fastjson2 documentation, kotlin-reflect is recommended when using Kotlin data classes or constructor-based parameter passing.

Without kotlin-reflect, constructor parameter names may not be resolved in some environments, which may cause deserialization of Kotlin classes to fail or produce incorrect results.

Example:


// FILE: Main.kt

import com.alibaba.fastjson2.JSON

data class User(
    val name: String,
    val age: Int,
)

fun main() {
    val json = """{"name":"Alice","age":30}"""

    // Without kotlin-reflect, deserialization of Kotlin classes
    // may fail or produce incorrect results in some environments.
    val user = JSON.parseObject(json, User::class.java)

    println(user)
}

The quick-fix adds a kotlin-reflect dependency to the affected module.

Quick-fix result in build.gradle.kts:


// FILE: build.gradle.kts
dependencies {
    implementation("com.alibaba.fastjson2:fastjson2:2.0.63")
    // or implementation("com.alibaba.fastjson2:fastjson2-kotlin:2.0.63")

    implementation("org.jetbrains.kotlin:kotlin-reflect:$kotlin_version") // added by quick-fix
}

Quick-fix result in pom.xml:


// FILE: pom.xml
<dependencies>
    <dependency>
        <groupId>com.alibaba.fastjson2</groupId>
        <artifactId>fastjson2</artifactId>
        <version>2.0.63</version>
    </dependency>
    <!-- or fastjson2-kotlin -->

    <!-- added by quick-fix -->
    <dependency>
        <groupId>org.jetbrains.kotlin</groupId>
        <artifactId>kotlin-reflect</artifactId>
        <version>${kotlin.version}</version>
    </dependency>
</dependencies>
