Reports Closeable or AutoCloseable resources that are not managed with the use { } function.

Resources that implement Closeable or AutoCloseable must be properly closed after use. The idiomatic Kotlin way is to call use { }, which automatically closes the resource even if an exception is thrown. Explicit close() calls are not exception-safe and should be replaced with use { }.

The inspection covers the following cases:

  • A closeable resource assigned to a local variable without being wrapped in use { }.
  • A closeable expression used directly (e.g. method call, also chain) without use { }.
  • A closeable expression returned as the last expression of a lambda block, without use { }.
  • A result of use { } that is itself a closeable resource not wrapped in another use { }.

Example (variable):


val stream = FileInputStream("file.txt") // resource is never closed safely
stream.read()

After the quick-fix:


FileInputStream("file.txt").use { stream ->
    stream.read()
}

Example (variable, last statement produces a value):


val stream = FileInputStream("file.txt")
val result = stream.read()

After the quick-fix:


val result = FileInputStream("file.txt").use { stream -> stream.read() }

Example (variable with explicit close — not exception-safe):


val stream = FileInputStream("file.txt")
stream.read()
stream.close()

After the quick-fix:


FileInputStream("file.txt").use { stream ->
    stream.read()
}

Example (expression):


getStream().also { it.read() }.read() // resource is never closed

After the quick-fix:


getStream().use { it.also { it.read() }.read() }

Example (lambda block returning a closeable):


run {
    AC() // returned but never closed
}

After the quick-fix:


run {
    AC()
}.use { }

The following cases are not reported:

  • Resources already wrapped in use { }, or chained with also { ... } before use { }.
  • Types that declare a close() method but do not implement Closeable or AutoCloseable.
  • Resources that are explicitly closed with close() before their derived values escape the enclosing scope.
