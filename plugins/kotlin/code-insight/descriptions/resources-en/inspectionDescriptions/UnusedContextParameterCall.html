Reports context(...) calls whose context arguments are never used inside the lambda body.

When none of the introduced context parameters are consumed, the entire context(...) call is redundant and the lambda body can be inlined. When only some context arguments are unused, the redundant arguments can be removed.

Remove redundant context call can be used to amend the code automatically.

Example:


    context(message: String)
    fun log() {}

    fun test() {
        context("string", 42) {
            log()
        }
    }

After the quick-fix:


    context(message: String)
    fun log() {}

    fun test() {
        context("string") {
            log()
        }
    }
