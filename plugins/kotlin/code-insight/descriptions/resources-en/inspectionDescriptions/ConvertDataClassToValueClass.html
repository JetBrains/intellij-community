Reports data classes that can be replaced by a full value class.

Example:


data class User(val firstName: String, val lastName: String)

After the quick fix is applied, with both functions selected:


value class User(val firstName: String, val lastName: String) {
    fun copy(firstName: String = this.firstName, lastName: String = this.lastName) = User(firstName, lastName)

    operator fun component1(): String = firstName
    operator fun component2(): String = lastName
}
