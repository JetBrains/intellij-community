Reports name-based destructuring entries whose destination name is _. Because _ is unusable, such an entry only extracts a value to discard it and can be removed without changing the semantics.

Full-form example:


  data class Foo(val bar: String, val qux: Int)

  (val _ = bar, val qux) = Foo("", 0)

The quick-fix removes the redundant underscore entry:


  (val qux) = Foo("", 0)

Short-form example (when name-based destructuring short form is enabled):


  val (_ = bar, qux) = Foo("", 0)

becomes:


  val (qux) = Foo("", 0)
