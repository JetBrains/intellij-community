Reports name-based destructuring entries whose destination name is _.

An underscore entry extracts a value and discards it.

If the inspection cannot confirm that removal preserves semantics, the quick-fix includes (may change semantics). Removal can skip side effects or exceptions from a getter, a delegate, or an uninitialized lateinit property. These fixes are unavailable in Fix All.

Full-form example:


  data class Foo(val bar: String, val qux: Int)

  (val _ = bar, val qux) = Foo("", 0)

The quick-fix removes the redundant underscore entry:


  (val qux) = Foo("", 0)

Short-form example (when name-based destructuring short form is enabled):


  val (_ = bar, qux) = Foo("", 0)

becomes:


  val (qux) = Foo("", 0)
