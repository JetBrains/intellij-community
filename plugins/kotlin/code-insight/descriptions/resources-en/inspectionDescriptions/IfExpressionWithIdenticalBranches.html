Reports an if expression when its then and else branches execute the same code.

The quick-fix removes the if and keeps one copy of the branch. If evaluating the condition may have side effects, the quick-fix is marked as potentially changing semantics.

Example:


  fun answer(useDefault: Boolean): Int =
      if (useDefault) 42 else 42

After you apply the quick-fix:


  fun answer(useDefault: Boolean): Int = 42
