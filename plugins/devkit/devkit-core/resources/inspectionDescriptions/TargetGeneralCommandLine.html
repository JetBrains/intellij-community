Reports GeneralCommandLine code that selects its process environment implicitly.

GeneralCommandLine can select a non-local process environment from its executable path or working directory. A target-native executable string can make this selection depend on the working directory. This behavior is fragile for projects in WSL and Dev Containers.

Convert an EelPath with asNioPath() when you must use GeneralCommandLine. Prefer EelExecApi when the execution environment is already available.
