Reports hand-written guards that rethrow a control-flow exception, such as if (e instanceof ControlFlowException) throw e; or if (Logger.shouldRethrow(e)) throw e;.

The quick-fix replaces such a guard with a call of the com.intellij.diagnostic.rethrowControlFlowException() helper, which recognizes the whole control-flow set (ControlFlowException and CancellationException, including ProcessCanceledException) and attaches the current stack trace as a suppressed exception.

Beyond being shorter, the helper is safer: a guard that checks only one of the types (for example CancellationException but not ControlFlowException) silently misses the other, while the helper rethrows both.

Unlike Logger.shouldRethrow(), the helper ignores the idea.log.rethrow.ce system property: it rethrows a control-flow exception even when the property is set to false.

Example:


// reported:
try {
  // ...
} catch (Throwable e) {
  if (e instanceof ControlFlowException) throw e;
  LOG.error(e);
}

// after the fix:
try {
  // ...
} catch (Throwable e) {
  rethrowControlFlowException(e);
  LOG.error(e);
}

The inspection runs only when the platform the plugin is built against has the helper.

See Background Processes Cancellation in IntelliJ Platform Plugin SDK docs for more details.
