Reports standard file operations that can require multiple RPC round trips to IJent.

For files in WSL or a Dev Container, NIO can delegate the operation to IJent. Some standard operations then require several sequential RPC calls.

EelFiles and EelFileUtils provide alternatives for both local files and files in other environments. When IJent performs the operation, these alternatives reduce the number of RPC calls.

Example:


// When IJent performs this operation, it can require multiple RPC round trips:
byte[] data = Files.readAllBytes(path);

// The optimized operation uses fewer RPC calls:
byte[] data = EelFiles.readAllBytes(path);
