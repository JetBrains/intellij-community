Reports SystemInfo OS checks in code that receives an EelApi, EelDescriptor, or EelPath.

SystemInfo always describes the OS where the IDE runs. Use it when this behavior is intended. If the code needs OS properties for the project environment or another environment supplied through EelApi, use EelPlatform. This API works consistently for local, WSL, and Dev Container environments.

The path annotation inspection reports missing annotations and incompatible local, native, and environment-aware paths.
