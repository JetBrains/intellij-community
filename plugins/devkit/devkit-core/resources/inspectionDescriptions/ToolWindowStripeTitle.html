Reports a toolwindow.stripe.* key that is not in the bundle the platform reads for the tool window.

The platform builds the key from the tool window ID. It adds the prefix toolwindow.stripe. and replaces every space with an underscore. For example, the tool window Version Control needs the key toolwindow.stripe.Version_Control. If the key is missing, the stripe button silently shows the ID.

The platform reads the key from one bundle only:

  • For the core plugin, it reads messages.IdeBundle.
  • For every other plugin, it reads the <resource-bundle> of the descriptor that declares the tool window. A content module does not inherit the bundle of its plugin. A <depends config-file> descriptor inherits it, unless it declares its own bundle.

To fix the problem, move the key to that bundle, or declare the bundle that holds the key.

The inspection does not report a tool window whose factory sets the stripe title in ToolWindowFactory.init().
